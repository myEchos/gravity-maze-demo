# Gravity Maze / 重力迷宫

A single-file HTML5 game with no backend or external dependencies.

- Mobile: enable device orientation, grant permission, then calibrate.
- PC: choose PC rotation mode and drag horizontally to rotate the maze.
- Collect checkpoints 1–4 in order before entering the center hole.
- Each round generates five separated walls and four reachable checkpoints.
- Sensitivity/gravity and friction settings are stored locally in your browser.

Open `index.html` for PC play. Mobile orientation requires an HTTPS page.
